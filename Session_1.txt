    post_id INT PRIMARY KEY,

    caption VARCHAR(255),
    post_date DATE,
    FOREIGN KEY (user_id) REFERENCES Users(user_id)
);

MySQL:
	1) MySQL is commonly used for web applications and websites.
	2) It is popular with applications built using PHP, Java, and Python.
	3) It is also widely used for small to large-scale applications.

PostgreSQL:
	1) PostgreSQL is commonly used for complex and large applications.
	2) It is popular in web applications, data analysis, and systems requiring advanced database features.
	3) It is known for strong support for SQL and data integrity.

Oracle:
	1) Oracle Database is commonly used in large enterprise systems.
	2) Banks, government organizations, and large companies often use it.
	3) It is designed to handle large amounts of data and high transaction loads.

SQLite:
	1) SQLite is commonly used in mobile and desktop applications.
	2) It is lightweight and does not require a separate database server.
	3) It is widely used in Android, iOS, and embedded applications.
