Test Scenario:
INSERT INTO Expenses (expense_id, user_id, amount)
VALUES (1, 1, 1000);
(If the wallet balance was 5000, the buggy trigger incorrectly changes it to 6000).

Corrected trigger:
DELIMITER //

CREATE TRIGGER deduct_expense
AFTER INSERT ON Expenses
FOR EACH ROW
BEGIN
    UPDATE Wallet
    SET balance = balance - NEW.amount
    WHERE user_id = NEW.user_id;
END //

DELIMITER ;
